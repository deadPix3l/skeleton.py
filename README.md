# Skeleton.py

This is a snippets-style skeleton project.
It is not meant to be the basis for your project.
Its merely a store of some knowledge, collecting some python specific things that
dont have a home, and a reference for some patterns.

It is not based on anything.
Any resemblance to existing projects is purely coincidental.

You may find that code which is already covered by other libraries is either duplicated or reimplemented here.
You will find multiple versions to acheive the same thing, functions and classes that are never called,
and commented out code (ruff ERA violations).

I do not claim you should build from this. I do not claim this is useful.
I do not claim it runs or tests.
I do not claim any code you find here is correct, stable, accurate, or compatible with any specific version of python.
This repos sole purpose is for a reference.

Pythons current version, at the time of writing is 3.14, however, most code here, unless otherwise stated,
should be 3.12 compatible.

This repo will feature little to no AI generated code,
however AI may be used to generate the documentation, comments, docstrings,
planning documents, github issues, etc. Although even then, this will be intentionally limited
due to current models low quality and sycophancy.
On the occasion that ai code is used, every single line was reviewed by me.
This will not be a slop project of everything under the sun.
